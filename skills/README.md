# Skills — Reglas de Desarrollo

Índice de skills modulares. Cargar solo la que aplica al contexto actual.

| Skill                                                        | Scope          | Cuándo usar                                               |
| ------------------------------------------------------------ | -------------- | --------------------------------------------------------- |
| [`scope-rule.md`](scope-rule.md)                             | Proyecto       | Decisiones de estructura, mover código entre carpetas     |
| [`container-presentational.md`](container-presentational.md) | Proyecto       | Crear o refactorizar componentes React                    |
| [`tdd-strict.md`](tdd-strict.md)                             | Semi-universal | Escribir tests o implementar features                     |

| [`work-methodology.md`](work-methodology.md)                 | Proyecto       | Metodología de trabajo, roles, ciclo de desarrollo        |

**Clasificación por Scope Rule:**

- **Universal**: reutilizable en cualquier proyecto (shared)
- **Proyecto**: específico de nutre-fit-dia (local)
- **Semi-universal**: aplicable a la mayoría de proyectos con mínima adaptación
